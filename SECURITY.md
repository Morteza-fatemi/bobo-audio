# Security Policy

Please do not report security vulnerabilities in public Issues.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow when it is enabled for this repository. If it is not available, contact the maintainer privately through the email listed in the repository profile and include:

- affected version or commit
- reproducible steps or proof of concept
- impact assessment
- suggested mitigation, if known

Please avoid sharing credentials, tokens, personal data, or full exploit code in public channels.

## Supported versions

Only the latest published version and the default branch are actively supported unless the project README states otherwise.
